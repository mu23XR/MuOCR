## 验收目标

- 同一行可使用多种可嵌入字体；按 Unicode 码点处理，不拆代理对；保留精确 Unicode 映射与字体资源关闭顺序。不支持字符给出可定位错误，保留 OCR 缓存，不静默换成空格。
- 清理控制、零宽/格式字符并规范空白，保留原文/简体开关；原始 OCR 缓存不改写。旧文字层检查点按新策略安全重建，不混合两套规范化规则。
- 缓存页增加确认后的批量清理，沿用工作根白名单、Worker/清理与重试互斥、持久清理标记、旧缓存不复活及输出保护；原文件、已导出文件、字体不进入删除范围。
- 基线与最终正式 Gradle 单测、Release 构建；混排/缺字/Unicode、清理中断/重试及旧模式迁移的针对性回归。需要设备验收时仅启动原有 MuMu 1，不触碰 0，不新建实例。
